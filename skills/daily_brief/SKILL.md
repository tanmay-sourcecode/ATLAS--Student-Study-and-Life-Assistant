# Skill: daily_brief
Read the student's classes, deadlines, and goals for the period, then produce a realistic, focus-protecting plan for the day/week.
Prioritize tasks by urgency and workload. Output a clear, concise dashboard containing:
1. Today's classes and recitations.
2. Upcoming deadlines within the next 3 days, sorted by urgency.
3. Recommended focus study blocks (e.g. 2-hour blocks) designed around the student's class schedule.
4. Keep the tone friendly, encouraging, and clear.
