# Skill: assignment_breakdown
Break down a single large assignment into smaller, actionable steps.
For each subtask, estimate:
1. Expected time to complete (e.g. 45 mins).
2. Priority level (High, Medium, Low).
3. Logical dependencies (e.g. 'Must complete parser before starting code generator').
4. Suggested study focus blocks.
Keep formatting clean, lightweight, and easy to scan.
