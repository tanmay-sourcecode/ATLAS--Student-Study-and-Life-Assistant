# Skill: email_draft
Draft a respectful, clear, and professional email.
Key requirements:
1. Provide a professional Subject Line.
2. Use an appropriate academic Greeting (e.g. 'Dear Professor [Name]').
3. Write a concise body paragraph specifying the main request (e.g. extension request, office hours inquiry) and a polite rationale.
4. Close politely (e.g. 'Best regards, [Student Name]').
Place bracketed placeholders (like '[Professor Name]') for missing variables, and state clearly that this draft must be approved by the student.
